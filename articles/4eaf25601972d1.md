## 概要

[MITRE ATT&CK® Navigator](https://mitre-attack.github.io/attack-navigator/) は、サイバー攻撃の知識ベースである [MITRE ATT&CK](https://attack.mitre.org/)のマトリクスを視覚的に探索・カスタマイズ・共有するための無料の Web ベースツール（オープンソース・ツール）です。

ソースは、 https://github.com/mitre-attack/attack-navigator で公開されており、セルフホストが可能です。

しかしながら、デフォルトでは、データを Mitre のサイトから取得しに行くため、インターネット接続ができない環境で動作させてもエラーとなり、何も表示されません。

この記事では、MITRE ATT&CK® Navigator をインターネット接続ができない環境で動作させる手順を説明します。

ただし、Techniques 等の検索は、外部サイトへリンクするため、動作しません。

また、環境準備には、インターネットに接続できる端末が必要となります。

## 筆者の環境


| 項目    | 値                                             |
| ------- | ---------------------------------------------- |
| CPU     | 11th Gen Intel(R) Core(TM) i7-1165G7 @ 2.80GHz |
| メモリ  | 16GB                                           |
| OS      | Fedora Linux 44 (Workstation Edition)          |
| node.js | v26.10.0                                       |

## 必要なソフトウェア

- node.js
- npm
- sed
- unzip
- wcurl

## ツール本体のダウンロードと展開

以下のコマンドでツール本体をダウンロードし、展開します。

```
$ wcurl -o attack-navigator.zip https://github.com/mitre-attack/attack-navigator/archive/refs/heads/master.zip
$ unzip attack-navigator.zip
```

この場合、 `attack-navigator-master` というディレクトリ内に展開されます。リリースバージョン等をダウンロードした場合は、以降、`master` を該当バージョンに読み替えてください。

## ATT&CK® STIX Data のダウンロードと展開

以下のコマンドで ATT&CK® STIX Data をダウンロードし、展開します。

```
$ wcurl -o attack-stix-data.zip https://github.com/mitre-attack/attack-stix-data/archive/refs/heads/master.zip
$ unzip attack-stix-data.zip
```

この場合、 `attack--stix-data-master` というディレクトリ内に展開されます。リリースバージョン等をダウンロードした場合は、以降、`master` を該当バージョンに読み替えてください。

## ATT&CK® STIX Data の必要ファイルをツール本体にコピー

以下のコマンドで展開した ATT&CK® STIX Data から必要なファイルをツール本体にコピーします。

```
$ cp -R attack-stix-data-master/{index.json,enterprise-attack,mobile-attack,ics-attack} attack-navigator-master/nav-app/src/assets/
```

## カレントディレクトリの変更

以下のコマンドでカレントディレクトリを変更します。

```
$ cd attack-navigator-master/nav-app
```

## 必要なライブラリのインストール

npm コマンドにより、必要なライブラリをインストールします。

```
$ npm install
```

脆弱性に対する警告が出ますが、対処すると動かなくなるので無視します。実運用する場合は、注意してください。

## 設定ファイルの修正

ローカルの ATT&CK® STIX Data を参照させるため、`src/assets/config.json` を修正します。

```
$ sed -i 's@"https://raw.githubusercontent.com/mitre-attack/attack-stix-data/master/index.json"@"assets/index.json"@' src/assets/config.json
```

ここで指定した `src/assets/index.json` もリモート URL が記述されているため、修正します。

```
$ sed -i 's@https://raw.githubusercontent.com/mitre-attack/attack-stix-data/master/@assets/@' src/assets/index.json
```

## ビルド

以下のコマンドでビルドを行います。

```
$ npx ng build
```

Google の Angular Team に使用データを送信するか聞かれるので `N` キーを押してください。

## インターネット接続を無効化しツールを起動

インターネット接続を無効化し、以下のコマンドでツールを起動します。

```
$ npx ng serve
```

表示されたアドレス `http://localhost:4200/` をブラウザーで開きます。

![](/images/2026-09-26-1.png)

`Create New Layer` から、`Enterprise ATT&CK` などを選択し、以下のような画面が表示されれば、成功です。

![](/images/2026-09-26-2.png)
