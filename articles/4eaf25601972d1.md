## 概要

[MITRE ATT&CK® Navigator](https://mitre-attack.github.io/attack-navigator/) は、サイバー攻撃の知識ベースである [MITRE ATT&CK](https://attack.mitre.org/)のマトリクスを視覚的に探索・カスタマイズ・共有するための無料の Web ベースツール（オープンソース・ツール）です。

通常、このツールはGitHubなど外部リソースへの接続を必要としますが、インターネット接続ができない環境で動作させるための手順を説明します。

**注意点:**
この手順では、外部データへのアクセスを完全に遮断し、ローカルにダウンロードしたデータのみを使用してツールを動作させます。そのため、Techniquesなどの検索機能は外部サイトへのリンクを伴うため、オフライン環境では動作しません。また、環境準備には、インターネットに接続できる端末が必要となります。

## 筆者の環境

| 項目    | 値                                             |
| ------- | ---------------------------------------------- |
| CPU     | 11th Gen Intel(R) Core(TM) i7-1165G7 @ 2.80GHz |
| メモリ  | 16GB                                           |
| OS      | Fedora Linux 44 (Workstation Edition)          |
| node.js | v26.10.0                                       |

## 必要なソフトウェア

- node.js
- npm
- sed
- unzip
- wcurl

## ステップ 1: ツール本体のダウンロードと展開

まず、MITRE ATT&CK® Navigator のツール本体をダウンロードし、展開します。

```bash
$ wcurl -o attack-navigator.zip https://github.com/mitre-attack/attack-navigator/archive/refs/heads/master.zip
$ unzip attack-navigator.zip
```

展開後、`attack-navigator-master` というディレクトリが作成されます。リリースバージョン等をダウンロードした場合は、以降、`master` を該当バージョンに読み替えてください。

## ステップ 2: ATT&CK® STIX Data のダウンロードと展開

次に、必要なATT&CK® STIX Dataをダウンロードし、展開します。

```bash
$ wcurl -o attack-stix-data.zip https://github.com/mitre-attack/attack-stix-data/archive/refs/heads/master.zip
$ unzip attack-stix-data.zip
```

展開後、`attack--stix-data-master` というディレクトリが作成されます。リリースバージョン等をダウンロードした場合は、以降、`master` を該当バージョンに読み替えてください。

## ステップ 3: 必要なファイルのコピー

展開したATT&CK® STIX Dataから、ツール本体に必要なファイルをコピーします。

```bash
$ cp -R attack-stix-data-master/{index.json,enterprise-attack,mobile-attack,ics-attack} attack-navigator-master/nav-app/src/assets/
```

## ステップ 4: カレントディレクトリの変更とライブラリのインストール

ツール本体のディレクトリに移動し、必要なライブラリをインストールします。

```bash
$ cd attack-navigator-master/nav-app
$ npm install
```

**【重要：警告について】**
`npm install` の実行時に脆弱性に関する警告が表示される場合があります。これらの警告は、ツールが正常に動作するために必要な依存関係に関するものであり、通常は無視して構いません。ただし、実運用する場合は、依存関係が意図しないものになっていないか確認することを推奨します。

## ステップ 5: 設定ファイルの修正

ローカルのATT&CK® STIX Dataを参照させるため、設定ファイル内のリモートURLをローカルパスに修正します。

1.  `src/assets/config.json` の修正:
    ```bash
    $ sed -i 's@"https://raw.githubusercontent.com/mitre-attack/attack-stix-data/master/index.json"@"assets/index.json"@' src/assets/config.json
    ```

2.  `src/assets/index.json` の修正:
    ```bash
    $ sed -i 's@https://raw.githubusercontent.com/mitre-attack/attack-stix-data/master/@assets/@' src/assets/index.json
    ```

## ステップ 6: ビルドと起動

設定が完了したら、ビルドを行い、ツールを起動します。

```bash
$ npx ng build
```
（この際、Google の Angular Team からデータ送信の確認が出ますが、`N` キーを押して続行してください。）

最後に、インターネット接続を無効化し、ツールを起動します。

```bash
$ npx ng serve
```

表示されたアドレス `http://localhost:4200/` をブラウザーで開いてください。

![](/images/2026-09-26-1.png)

`Create New Layer` から、`Enterprise ATT&CK` などを選択し、画面が表示されれば、オフライン環境での動作に成功です。

![](/images/2026-09-26-2.png)
